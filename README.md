📚 Book Store Website

A modern and responsive multi-page bookstore/café website built using HTML, CSS, and JavaScript. This project showcases a full site experience with a home page, book catalog with search, an events listing, and a contact form — all sharing a consistent, mobile-friendly navigation menu.

✨ Features

- Responsive multi-page layout (Home, Books, Events, Contacts)
- Mobile-friendly hamburger navigation menu that turns into an X icon when open
- Dropdown-style navigation menu with a dedicated close button
- Live book search/filter on the Books page — results update as you type
- Contact form validation (checks for empty name and valid email before "submitting")
- Responsive book card grid — 1 column on mobile, 3 columns on wider screens
- Shared stylesheet across all pages for consistent design
- Clean, simple, easy-to-read code structure

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
